What this small model does — and where it stops

Fit only on the examples

The model builds word and adjacent content-word-pair features from the labeled examples. Inverse document frequency is fitted on those examples only. Exact copies of the query are removed first; conflicting labels are rejected.

Make rule context explicit

Features whose words appear in the rule receive a fixed 1.5× weight. Normalized TF–IDF vectors are compared by cosine similarity. Up to two nearest examples per label determine the signed margin. This is surface matching, not semantic understanding.

Know the limit

Low overlap produces “not enough lexical evidence.” Similarity cannot reliably resolve intent, negation, quotation, exceptions or unseen wording. These editable examples provide no accuracy estimate. No Qwen model or private project inference code is included.
