## Interpretation limits

Training contains 2,029 rows and only two labeled rules. Exact duplicate grouping and validation-text purging reduce specific leakage routes but do not rule out paraphrases or shared sources. All ten preview test comments overlap training, so preview predictions only verify submission plumbing. These local AUCs and synthetic smoke-test results are not Kaggle leaderboard scores.

The generalization gap justifies investigating semantic models; it does not establish which architecture will win. Repeated model selection on two held-out rules weakens their value as an independent final evaluation. See [the next experiment](../../docs/PHASE_2.md).
