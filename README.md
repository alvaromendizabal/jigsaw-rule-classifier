# Jigsaw · Rule-conditioned comment classification

An NLP research project by Alvaro Mendizabal, studying how classifiers generalize to new community rules.

The first release is being reviewed through a pull request. It includes reproducible experiments, checksummed checkpoints, AWS persistence, explicit tests, observable progress, offline Kaggle inference, and an audited real-data baseline.

Code and aggregate evaluation evidence will be published here. Competition text, credentials, and model weights remain outside Git.
